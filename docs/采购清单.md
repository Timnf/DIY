# 采购清单

## 1. 入门阶段必买

### 主控
- **ESP32 开发板** ×1
  用途：作为第一阶段主控，负责读取传感器、控制电机和状态灯。

### 运动底盘
- **4WD 小车底盘套件** ×1
  用途：作为机器人底盘，包含车架、电机、轮子。

- **TB6612FNG 电机驱动板** ×1
  用途：驱动左右电机，效率通常高于 L298N，发热更低。

### 传感器
- **HC-SR04 超声波模块** ×1
  用途：检测前方障碍物距离，做自动避障。

### 供电
- **18650 电池盒 + 电池** ×1 套
  用途：给底盘和主控提供移动电源。

- **LM2596 降压模块** ×1
  用途：把电池输出稳定到 ESP32 和外设可用电压。

### 调试材料
- 面包板 ×1
- 杜邦线若干
- LED 若干
- 220Ω 电阻若干

### 工具
- 万用表 ×1
- 电烙铁套装 ×1
- 螺丝刀套装 ×1

---

## 2. 推荐加购

- **SG90 舵机** ×1
  用途：让超声波模块转动，扩大探测范围。

- **红外避障模块** ×2
  用途：辅助近距离避障。

- **蜂鸣器** ×1
  用途：给机器人增加声音反馈。

- **RGB 灯带 / RGB LED**
  用途：增加互动效果。

---

## 3. 第二阶段可购买

- Raspberry Pi 4B / 5
- 摄像头模块 / USB 摄像头
- 麦克风模块
- 小音箱或功放模块

---

## 4. 购买原则

1. 优先买通用件，不要一开始买太冷门模块。
2. 优先保证供电稳定，电源问题会导致最多故障。
3. 传感器和电机驱动至少多准备 1 个备件。
4. 购买时尽量选择资料多、评价稳定的常见型号。
