# ESP32 快乐小车控制程序

## 功能概览
当前代码实现了第一版核心功能：
- 双电机前进 / 后退 / 左转 / 右转
- LED 状态切换
- 超声波距离检测
- 自动避障基本逻辑

## 当前控制策略

### 正常情况
当检测到前方距离大于安全阈值时：
- 小车持续前进
- LED 常亮表示运行中

### 障碍物接近时
当距离小于安全阈值时：
1. 小车停止
2. 短暂后退
3. 向右转尝试避开障碍
4. 再继续前进

## 使用说明
1. 打开 Arduino IDE。
2. 安装 ESP32 开发板支持。
3. 打开 `esp32_car.ino`。
4. 根据你的接线修改引脚定义。
5. 编译并烧录到 ESP32。
6. 打开串口监视器观察距离和状态输出。
