# 产品 01：快乐小车机器人

## 产品目标
做出第一台真正能跑起来的 DIY 机器人。

## 本产品当前范围
- 底盘移动
- 超声波避障
- LED 状态指示
- ESP32 控制逻辑

## 目录说明
- `hardware/`：接线图说明、装配记录、器件安装说明。
- `software/`：控制程序、调试说明、后续功能扩展。

## 第一版研发顺序
1. 完成供电检查。
2. 完成电机驱动接线。
3. 验证基础前进 / 后退 / 转向。
4. 接入超声波。
5. 做自动避障。
6. 追加遥控模式。
