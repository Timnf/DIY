# DIY 机器人快乐计划（中文）

这个项目是给你量身定制的：
**一边学习软硬件，一边亲手做出一个能动、能互动、让你开心的机器人。**

---

## 1) 项目目标（先做出来，再慢慢升级）

### 阶段 A：快乐小车（2~4 周）
- 能前进 / 后退 / 转向
- 能避障（超声波）
- 能通过手机网页或蓝牙控制
- 有灯光反馈（LED）

### 阶段 B：会“说话”的机器人（4~8 周）
- 加上麦克风和喇叭
- 做简单语音命令（如“前进”“停下”）
- 加摄像头，实现简单目标识别（比如识别人脸或颜色）

### 阶段 C：你的专属陪伴机器人（长期）
- 自定义外壳（3D 打印或手工搭建）
- 加入情绪灯效、动作编排
- 接入大模型 API，做聊天互动

---

## 2) 你要买什么（高性价比清单）

> 预算参考：
> - **入门版**：300~500 RMB
> - **进阶版**：700~1500 RMB

### A. 核心主控（二选一）
1. **ESP32 开发板（推荐入门）**
   - 便宜、资料多、支持 Wi-Fi/蓝牙
   - 适合做小车控制、手机连接
2. **Raspberry Pi 4B / 5（推荐进阶）**
   - 能跑 Linux、Python、OpenCV、语音
   - 适合视觉 + AI 功能

> 建议：先买 ESP32 做第一台车；第二台再用树莓派升级。

### B. 底盘与运动
- 2WD/4WD 智能小车底盘套件（含电机、轮子）
- 电机驱动板（L298N 或 TB6612FNG）
- 舵机（SG90）1~2 个（做云台或小机械动作）

### C. 传感器
- 超声波模块 HC-SR04（避障）
- 红外避障模块（可选）
- MPU6050（姿态传感器，可选）
- 摄像头模块（树莓派摄像头或 USB 摄像头）

### D. 供电与连接
- 18650 电池 + 电池盒 + 充电模块（注意安全）
- 降压模块（如 LM2596）
- 面包板 + 杜邦线（公对公、公对母、母对母）
- 开关、电阻包、LED 灯若干

### E. 工具（一定要有）
- 万用表（必须）
- 电烙铁 + 焊锡丝 + 吸锡器
- 螺丝刀套装、热熔胶枪（固定结构很好用）

### F. 软件与学习环境（免费为主）
- **Arduino IDE**（ESP32）
- **VS Code + PlatformIO**（进阶开发）
- **Python 3**（树莓派/PC 视觉与AI）
- **Git + GitHub**（保存你的作品）

## 3) 学习路线（软件 + 硬件一起学）

### 第 1 周：电路基础
- 认识电压 / 电流 / 地线（GND）
- 点亮 LED，学会串联电阻
- 用万用表测电压

### 第 2 周：单片机控制
- ESP32 GPIO 输出控制 LED
- PWM 控制电机速度
- 串口打印调试信息

### 第 3 周：机器人动起来
- 电机驱动接线
- 小车前后左右控制
- 调整供电和重心，让小车跑得稳

### 第 4 周：加入“感知”
- 超声波避障
- 简单状态机（前进 -> 检测 -> 转向 -> 再前进）

### 第 5~8 周：智能升级
- 手机网页控制（ESP32 Web Server）
- 树莓派 + OpenCV 识别颜色/人脸
- 接语音或聊天 API 做互动

---

## 4) 一个简单的“第一版机器人”建议配置

如果你现在就下单，建议买这一套：

- ESP32 开发板 ×1
- 4WD 小车底盘套件 ×1
- TB6612FNG 电机驱动 ×1
- HC-SR04 超声波 ×1
- 18650 电池盒 + 2 节电池 ×1
- LM2596 降压模块 ×1
- 面包板 + 杜邦线若干
- LED 灯、220Ω 电阻若干
- 万用表 ×1

这套可以完成：
- 手动遥控小车
- 自动避障
- 灯光互动

---

## 5) 给你的建议（你是中国男孩，实战最重要）

- 先做“能跑起来”的版本，不要一开始追求最酷。
- 每完成一个小功能就拍视频记录，你会越来越有成就感。
- 遇到问题先用“最小系统”排错：电源 -> 接线 -> 代码 -> 模块。
- 多看中文社区（B站、CSDN、立创开源、GitHub），跟着做 1~2 个项目后你就能自己改。
