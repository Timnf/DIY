# DIY 机器人研发仓库

这是一个**按阶段推进**的中文机器人研发项目仓库。

目标不是只写一篇购买清单，而是从 0 开始，持续完成：
- 需求定义
- 采购准备
- 硬件搭建
- 软件开发
- 联调测试
- 过程记录
- 最终文档沉淀

也就是说，后面每做出一个产品、一个功能、一个版本，都会在这个仓库里留下对应的：
- 文档
- 代码
- 接线说明
- 测试记录
- 开发日志

---

## 项目方向

当前总项目围绕“让人开心的 DIY 机器人”展开，分 3 个阶段推进：

### 阶段 1：快乐小车机器人
先做出一个稳定可运行的机器人底盘，具备：
- 前进 / 后退 / 左转 / 右转
- LED 状态提示
- 超声波避障
- 手动控制 + 自动模式切换

### 阶段 2：会互动的机器人
在小车底盘稳定后继续增加：
- 麦克风 / 喇叭
- 简单语音控制
- 摄像头视觉识别
- 手机端交互

### 阶段 3：陪伴型机器人
长期目标：
- 更好的外观结构
- 互动动作编排
- 情绪反馈
- 接入 AI 能力

## 第一阶段研发节奏建议

### 第 1 步：先把硬件买齐
先按采购清单购买基础件，不要一开始追求“功能最全”，优先保证：
- 主控正常供电
- 电机可驱动
- 传感器可读数

### 第 2 步：先做最小可运行系统
第一阶段不要直接上复杂 AI，先做出最小闭环：
- 通电
- 电机可动
- LED 可亮
- 超声波能测距离
- 机器人能根据距离停止 / 转向

### 第 3 步：一边开发一边记录
每次推进都补充：
- 改了什么
- 为什么改
- 怎么测试
- 结果如何
- 下一步做什么

这样这个仓库就会越来越像真正的研发项目，而不是零散笔记。
